# The Indian Wedding — Luxury Indian Wedding Planners

Luxury Indian wedding planning landing page featuring palaces, havelis, and destination celebrations.

## Tech Stack
- **Framework:** React 19 + Vite
- **Routing:** React Router v7
- **Animations:** Framer Motion + GSAP ScrollTrigger
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
